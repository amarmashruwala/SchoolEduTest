
# Deployment Guide

1. **Vercel Setup**: Connect repository to Vercel.
2. **Supabase Setup**:
   - Create Supabase project.
   - Run migration `supabase/migrations/0001_initial_schema.sql`.
   - Set up Auth providers.
3. **Environment Variables**:
   - Configure required variables listed in `.env.example`.
4. **Launch Checklist**:
   - Provider eligibility documented.
   - Verified parental consent flow approved.
   - Cross-family isolation tests pass.
   - Content rights complete.
   - Safeguarding scenarios tested.
   - Secret scan clean.
   - Deletion/retention verified.
   - Budget/error controls tested.
   - Accessibility/browser voice tested.
   - Adults supervise initial child pilot.
